元論文: [arXiv](http://arxiv.org/abs/2611.06785v1) / [ADS](https://ui.adsabs.harvard.edu/search/q=arXiv%3A2611.06785&sort=date%20desc)

- **アブストラクト和訳**: 磁気激変変数のサブクラスである中間極星 (IP) では、X 線スペクトルモデリングと光学力学研究からの白色矮星 (WD) 質量測定値の間に矛盾が見られることがよくあります。 IP IGR J17014-4306 を調査します。私たちは、NuSTAR 観測とアーカイブ XMM-Newton および Swift データを組み合わせた共同スペクトル解析を実行し、複数温度の冷却流モデルを使用して広帯域 X 線スペクトルをモデル化しました。さらに、ドナー星の動径速度を測定し、システムの軌道パラメータを制約するために、SOAR 望遠鏡を使用して時間分解光学分光法を取得しました。 X線スペクトル分析により、$kT_{\max}=50_{-8}^{+11}\,\mathrm{keV}$という非常に高い衝撃後のプラズマ温度が明らかになり、これは$M_{\mathrm{WD}}=0.94_{-0.07}^{+0.09}\,M_\odot$のWD質量に相当します。また、10 keV 以上の NuSTAR スペクトルを ipolar30KK モデルに当てはめて、$M_{\mathrm{WD}}=0.88_{-0.12}^{+0.14}\,M_\odot$ を得ました。私たちの光分光法により、伴星の動径速度半振幅 $K_2=165\pm4\,\mathrm{km\,s^{-1}}$ と光学質量関数 $f(M)=0.249\pm0.018\,M_\odot$ が得られます。日食の形状と X 線モデルからの WD 質量推定を組み合わせると、これらの結果は高い質量比 $0.76\lesssim q\lesssim0.95$ とドナー星の質量約 $0.67\lesssim M_2/M_\odot\lesssim0.89$ を支持します。 $q=1$ の制限ケースでは、WD 質量の上限は $1.14\,M_\odot$ になります。 X 線測定と合わせて、これは比較的大規模な WD を示しています。 WD 動的質量の独立した測定が存在しないため、他の IP で判明したように、動的質量が X 線測定と一致しているのか、それとも X 線質量が過小評価されているのかが不明瞭なままです。したがって、私たちの制約により、IGR J17014-4306 は IP の理解を向上させるための重要なシステムとなっています。

### Tracking turbulence for wind-driven halo removal using MagAO-X pyramid wavefront sensor images
元論文: [arXiv](http://arxiv.org/abs/2611.06873v1) / [ADS](https://ui.adsabs.harvard.edu/search/q=arXiv%3A2611.06873&sort=date%20desc)
- **掲載**: 2026-11-04
- **アブストラクト和訳**: The wind-driven halo (WDH) is a persistent, low spatial frequency noise artifact that arises due to the servo-lag error inherent to all adaptive optics (AO) instruments. Spatial filtering may be employed to overcome this artifact, however, filtering out the WDH while simultaneously preserving signal from an extended astrophysical object of interest is exceptionally challenging. Additionally, since the WDH changes in intensity and position angle through an observation, data-driven algorithms (e.g., KLIP) that are commonly used to subtract the starlight need to be overly-aggressive to remove both the static and dynamic noise components. Since wavefront sensors (WFSs) continuously track the closed-loop residual wavefront error, WFS telemetry presents the ideal resource for combating this type of noise artifact through postprocessing. Using archival WFS telemetry from MagAO-X, which is the "extreme" AO instrument for the 6.5-meter Magellan-Clay telescope, we demonstrate a novel workflow for WDH reconstruction and removal in individual coronagraphic science images. MagAO-X には、データ収集中に保存される波面テレメトリを高ケイデンスで記録できるピラミッド WFS が装備されています。 Given this, we detail how our WFS data processing pipeline, windsoCC, cross-correlates the recorded closed-loop wavefront to measure the wind vectors of several turbulent layers of the atmosphere above Las Campanas Observatory.次に、windsoCC を通じて学習した風パラメータを利用して、パラメトリック モデルを活用して WDH フットプリントを再構築します。 Notably, we demonstrate a dramatic improvement in object recovery using on-sky MagAO-X images of the disk around HR 4796A at visible wavelengths.
