- **アブストラクト和訳**: 16年間の静止状態を経て、EXO 0748-676は2024年3月に予期せず爆発に戻った。しかし、前回の爆発(1985～2008年)とは全く対照的に、EXO 0748-676は約10か月の爆発を経て2025年1月に静止に戻った。ここでは、電波から X 線までの波長をカバーする 9 つの観測施設からのデータを照合し、2024/25 年のバーストに関する最初の多波長研究を提供します。 1985 年の爆発とは異なり、上昇と減衰の両方が X 線と光の波長で完全に捉えられています。光度曲線は、標準的な一時的低質量 X 線バイナリー アウトバーストの特徴を示しません。その代わり、2024/25 年のバースト中、X 線と光束は適度に安定したままです。 EXO 0748-676 の豊富な光学データから、歪んだ光位相曲線と、約 11000K の外側円盤で水素再結合が始まり、バーストの終わりに急速な減光が始まるまで続く、照射に支配された光学光曲線が明らかになりました。 XMM-Newton と NICER による X 線観測により、EXO 0748-676 は初期には大きく隠されており、スペクトルでは軟 X 線の寄与が減衰していることが明らかになりました。初期の遮蔽の正確な原因は依然として不明であるものの、塊状のイオン化吸収体を含むスペクトルモデルが遮蔽を説明していることがわかりました。 X線色彩分析によると、EXO 0748-676は約10か月間のバーストのほとんどをかすかな硬い状態で過ごしたことが示されています。 EXO 0748-676 はバーストの終わりに向けて明るさがわずかに増加しましたが、ソフトスペクトル状態にはなりませんでした。この動作は、失敗した遷移アウトバーストの特徴です。

### XClass: An Automated Multiwavelength Machine-Learning Pipeline for Classification of Extragalactic X-ray Sources. I. Pipeline Description
