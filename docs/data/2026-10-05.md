- **アブストラクト和訳**: 熱 X 線パルス プロファイルは、表面放射に対する重力光の曲がりや回転の影響により、中性子星の質量と半径を制限します。強化された X 線タイミングおよび偏光測定 (eXTP) ミッションから期待される精度により、繰り返しのモデル評価に必要な効率を維持する、より正確な光曲げ解析式の作成が促進されます。曲げ、伝播遅延、および回転楕円面によるレンズ近似を組み合わせた扁平シュワルツシルト (OS) 近似内で洗練された解析磁束式を導出します。そのプロファイルを、同じ回転楕円面上の数値シュワルツシルトおよび二次ハートル-ソーン光線追跡と比較します。比較では、等方性黒体放射を伴う 300 Hz での選択された 2 スポット構成と、表面離心率の 3 つの選択肢 (自由に指定された値、均一に回転するニュートン流体のマクローリン関係、および回転中性子星表面へのフィット) を使用します。これらのケース全体で、球面シュワルツシルト プラス ドップラー (S+D) モデルの RMS 束の差は $6.50-21.39\%$ であるのに対し、Hartle-Thorne 基準と比較して、洗練された OS プロファイルでは $1.76-1.98\%$ の RMS 束の差があります。すべての差は、位相平均された基準磁束に対して正規化されます。 Schwarzschild と Hartle-Thorne レイ トレーシングの対応する差異は $1.1\%$ 未満のままです。これらの比較により、解析的な光子伝達の誤差が、表面変形および回転する外部時空の影響から分離されます。調査した構成では、扁平率を考慮すると、レイ トレーシングとの一致が大幅に改善されます。このモデルは、プロファイル変更の物理的な原因を明示しながら、分析計算の速度を維持します。

- **アブストラクト和訳**: FlashSinkhorn などのエントロピー最適トランスポート (EOT) 用のストリーミング GPU ソルバーは、高密度カーネルの保存を回避しますが、Sinkhorn の反復ごとにすべての $n\times m$ ポイント ペアを評価します。我々は、低次元点群上の二乗ユークリッドコストのソルバーである \textbf{FlashSinkhorn~2} (FS2) を紹介します。これは、2 つのステージを結合することによって、単一の GPU 上で規定の限界残差まで大規模な離散 EOT 問題を解決します。粗いステージはセルの重心で解決し、ポテンシャルをすべてのポイントにリフトし、サンプリングされたマージン チェックがリフトを拒否した場合、セントロイドで続行し、ほとんどのポイント レベルの更新を置き換えます。次に、ブロックスパースファインステージにより、粗い更新では不可能なセントロイドエラーが除去されます。その Morton 順序ブロックはスクリーニングと融合テンソルコア実行をサポートし、ブロック質量によって設定されたしきい値は、すべての行と列に対する省略された各タイルの寄与を制限します。合成ベンチマークでは、FS2 は 32 問題すべてで目標残差、10 問題で GeomLoss マルチスケールに到達しました。1 つの A100 上で、FS2 は平均粒子間距離に等しいエントロピー ブラーで、宇宙論的 $N$ 体シミュレーションからの 2 つの $1.34\times10^8$ 粒子測定間の離散 EOT を 2.5 時間未満で 0.01 以下の全粒子周辺残差まで解きます。私たちの知る限り、これは数時間以内にこの精度で解決された最大の離散 EOT 問題です。再現性を高めるために、https://github.com/ot-triton-lab/flash-sinkhorn でオープンソース実装をリリースします。
