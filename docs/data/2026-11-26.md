- **アブストラクト和訳**: ミリ秒パルサー (MSP) は球状星団 (GC) のガンマ線放出の原因であると広く考えられていますが、基礎的な MSP ガンマ線視度関数は依然として不明です。後者の既存の GC ベースの決定は、多くの場合、各クラスター内の MSP の数に関する外部処方に依存します。この研究では、天の川銀河 GC の MSP ガンマ線視感度関数をガンマ線スペクトル エネルギー分布 (SED) から直接制約し、大規模な GC サンプルの共同解析でも計算上実行可能な推論戦略を確立しました。各 GC が普遍的な対数正規輝度関数から輝度が引き出される MSP の集団をホストする順モデルを構築します。合成 GC SED は、個々の MSP スペクトルを合計することによって生成され、最初に尤度ベースのネストされたサンプリング手法を使用して事後分布を推論し、次にシミュレーション ベースの推論 (SBI) アプローチを使用します。共同モデル化されたクラスター (およびクラスター固有の潜在パラメーター) の数が増加すると、尤度ベースの手法が急速に非実用的になるのに対し、SBI アプローチはサンプル サイズに応じて緩やかにスケールし、直接サンプリングが可能な領域で尤度ベースの事後分布を再現する様子を示します。次に、36 個の GC 関連ソースのサンプルの 4FGL-DR4 カタログの Fermi-LAT SED に SBI パイプラインを適用し、個別に検出された MSP をホストする 2 つのクラスターの専用の位相分解 ON/OFF SED によって強化されます。実際のデータサンプルについては、相補的な多波長情報を介してクラスター固有の MSP 数を制約する以前の分析と一致する視感度関数パラメータに関する有益な制約を取得します。
