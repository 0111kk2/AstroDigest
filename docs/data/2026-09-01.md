- **アブストラクト和訳**: SN 2025wny は、z = 2.015 にある重力レンズの水素が少ない超光度超新星 (SLSN-I) です。現在までに、これは最も広範囲に観測された高赤方偏移コア崩壊 SN であり、どの SLSN よりも詳細な静止フレーム UV 観測が行われています。 JWST、ケック、VLT、ジェミニ、パロマー 200 インチ、ウェンデルシュタインのフラウンホーファー望遠鏡、リバプール望遠鏡などのいくつかの施設から、ピーク後 +80 日 (静止フレーム) までの高密度にサンプリングされた静止フレーム UV から光学測光および分光法を紹介します。レンズ倍率を補正すると、SN 2025wny はレストフレーム 1500 ～ 4230 Å で $L_{\rm Peak}\gtrsim4\times10^{44}$ erg s$^{-1}$ のピーク擬似ボロメトリック光度に達し、典型的な SLSNe-I の光度範囲内に収まります。 SN 2025wny は、FUV の光曲線プラトーと推定される黒体温度の上昇と一致する +20 ～ 60 d の FUV における連続体過剰および鋭いスペクトル特徴など、いくつかの異常な特徴を示します。 SN 2025wny のスペクトルはまた、UV ラインブランケットがほとんど、またはまったく示されていないこと、高温にもかかわらず明らかな O II 吸収がないこと、および C II、H$α$、およびおそらく He I の証拠を示しています。光曲線モデリングは、SN 2025wny がハイブリッドまたは非標準の電源を必要とする可能性があることを示唆しています。この研究は、高赤方偏移 SLSNe に関する最初の詳細な制約の一部を提供し、Rubin と Roman によって発見された高赤方偏移 SLSNe を識別および解釈するための重要なスペクトル基準および測光基準として SN 2025wny を確立しました。

### JWST telemetry combined with active coronagraphy: raw contrast predictions for exoplanet imaging with the Habitable Worlds Observatory
元論文: [arXiv](http://arxiv.org/abs/2608.28322v1) / [ADS](https://ui.adsabs.harvard.edu/search/q=arXiv%3A2608.28322&sort=date%20desc)
- **掲載**: 2026-08-28
- **アブストラクト和訳**: 私たちは、$10^{-10}$ の生のコントラスト レベルで太陽に似た星の周りの地球外イメージングを目標とする、ジェームズ ウェッブ宇宙望遠鏡 (JWST) とハビタブルワールド天文台 (HWO) の間の技術的ギャップを定量化しました。 JWST の主セグメントミラーの飛行中のテレメトリを使用して、ローマ宇宙望遠鏡 (RST) のコロナグラフ装置 (CGI) に触発された最新のコロナグラフ装置を備えた JWST のような望遠鏡をシミュレートします。これは、セグメント化された遮るもののない軸外望遠鏡でのアポダイズ瞳リオ コロナグラフとアクティブ変形ミラー波面制御を特徴としています。我々は、100 Hzの高速制御周波数で非常に明るい星(等級4より明るい)に対して約$10^{-10}$の生コントラストを達成できるが、このレベルの制御では、より暗い星のJWST振幅誤差を補正するのに十分な信号がまだ不足していることを示します。我々は、波面安定性の10倍の改善は、最大11等級までの星について、リアクションホイールの振動がないと仮定して、考慮されたすべての制御周波数(1Hzから100Hz)にわたってこの能力を$10^{-10}$の生コントラストに拡張するのに十分であることを示した。これらの結果は、JWSTが実証した熱機械的安定性をHWOの要件に結び付ける新たな定量的ベンチマークを確立し、アクティブな波面制御が星の構造安定性の要求を緩和することを示している。波面の安定性は、HWO が地球外イメージングの目標を達成するために埋めなければならない重要な技術的ギャップであると特定しています。
